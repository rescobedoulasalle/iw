
# GUÍA DE PRÁCTICA: INVESTIGACIÓN Y EXPOSICIÓN SOBRE TECNOLOGÍAS FRONTEND

**Curso:** Ingeniería Web  
**Unidad temática:** Tecnologías Frontend  
**Modalidad:** Trabajo colaborativo  
**Número de grupos:** 6  
**Duración:** 2 horas  
**Tecnologías:** React, Vue.js y Angular

---

## 1. PRESENTACIÓN

La presente guía de práctica tiene como finalidad que los estudiantes conozcan, analicen y comparen las principales tecnologías utilizadas en el desarrollo Frontend de aplicaciones web modernas.

La actividad se desarrollará mediante la lectura y análisis de artículos científicos publicados en revistas o conferencias académicas. Cada grupo tendrá asignado un tema y un artículo científico de referencia, a partir del cual deberá identificar los fundamentos teóricos, arquitectura, metodología, resultados y conclusiones de la investigación.

La práctica comprende dos momentos:

- **Primera hora:** lectura, análisis del artículo científico y preparación de la exposición.
- **Segunda hora:** exposición de resultados, discusión y retroalimentación con todo el salón.

## 2. OBJETIVOS DE APRENDIZAJE

Al finalizar la actividad, los estudiantes serán capaces de:

1. Identificar las características y arquitectura de React, Vue.js y Angular.
2. Analizar artículos científicos relacionados con tecnologías Frontend.
3. Reconocer las ventajas, limitaciones y escenarios de aplicación de cada tecnología.
4. Interpretar resultados de investigaciones científicas relacionadas con el rendimiento web.
5. Comparar diferentes enfoques de desarrollo de interfaces web.
6. Comunicar resultados de investigación mediante exposiciones técnicas.

## 3. DISTRIBUCIÓN DE TEMAS POR GRUPOS

Se organizarán seis grupos de trabajo. Cada tecnología será estudiada desde dos perspectivas: fundamentos y arquitectura, y rendimiento y gestión de datos.

| Grupo | Tecnología | Tema de investigación |
|---|---|---|
| 1 | React | Fundamentos, arquitectura y desarrollo basado en componentes. |
| 2 | React | Rendimiento, gestión del estado y aplicaciones SPA. |
| 3 | Vue.js | Fundamentos, arquitectura reactiva y componentes. |
| 4 | Vue.js | Rendimiento, gestión del estado y aplicaciones SPA. |
| 5 | Angular | Fundamentos, arquitectura y desarrollo estructurado. |
| 6 | Angular | Rendimiento, gestión de datos y aplicaciones empresariales. |

## 4. ARTÍCULOS CIENTÍFICOS Y ACTIVIDADES POR GRUPO

### GRUPO 1: REACT – FUNDAMENTOS Y ARQUITECTURA

**Tema:** Arquitectura basada en componentes y construcción de interfaces de usuario.

**Artículo científico de referencia:**

*Evaluating the performance of web rendering technologies based on JavaScript: Angular, React, and Vue.*

Publicado en: IEEE Latin American Computer Conference (CLEI), 2022.

DOI: https://doi.org/10.1109/CLEI56649.2022.9959901

**Aspectos que deberá investigar:**

1. ¿Qué es React y para qué se utiliza?
2. ¿Qué es el Virtual DOM?
3. ¿Cómo funciona la arquitectura basada en componentes?
4. ¿Qué son JSX, props y componentes?
5. ¿Qué ventajas ofrece React en el desarrollo de interfaces?
6. ¿Qué características diferencian a React de otros frameworks?

### GRUPO 2: REACT – RENDIMIENTO Y GESTIÓN DEL ESTADO

**Tema:** Gestión del estado, Hooks y rendimiento de aplicaciones React.

**Artículo científico de referencia:**

*Evaluating the performance of web rendering technologies based on JavaScript: Angular, React, and Vue.*

Publicado en: IEEE Latin American Computer Conference (CLEI), 2022.

DOI: https://doi.org/10.1109/CLEI56649.2022.9959901

**Aspectos que deberá investigar:**

1. ¿Qué es el estado (State) en React?
2. ¿Qué función cumplen los Hooks?
3. ¿Cómo funcionan useState y useEffect?
4. ¿Qué factores afectan el rendimiento de una aplicación React?
5. ¿Qué son las aplicaciones SPA?
6. ¿Qué resultados presenta el artículo sobre React frente a Angular y Vue.js?

### GRUPO 3: VUE.JS – FUNDAMENTOS Y ARQUITECTURA REACTIVA

**Tema:** Arquitectura reactiva y desarrollo progresivo de interfaces web.

**Artículo científico de referencia:**

Bogusz, D., Ciszewski, P., & Pańczyk, B. (2024). *Performance analysis of web application client layer development tools using Angular, React and Vue as examples.*

Revista: Journal of Computer Sciences Institute, 32, 223–230.

DOI: https://doi.org/10.35784/jcsi.6299

**Aspectos que deberá investigar:**

1. ¿Qué es Vue.js y cuál es su filosofía de desarrollo?
2. ¿Cómo funciona la arquitectura basada en componentes?
3. ¿Qué es la reactividad?
4. ¿Qué son las directivas de Vue.js?
5. ¿Qué función cumple el sistema de plantillas?
6. ¿Qué ventajas ofrece Vue.js para construir interfaces?

### GRUPO 4: VUE.JS – RENDIMIENTO Y GESTIÓN DEL ESTADO

**Tema:** Gestión de datos, reactividad y rendimiento de aplicaciones Vue.js.

**Artículo científico de referencia:**

Bogusz, D., Ciszewski, P., & Pańczyk, B. (2024). *Performance analysis of web application client layer development tools using Angular, React and Vue as examples.*

Revista: Journal of Computer Sciences Institute, 32, 223–230.

DOI: https://doi.org/10.35784/jcsi.6299

**Aspectos que deberá investigar:**

1. ¿Cómo se actualizan los componentes cuando cambian los datos?
2. ¿Cómo se gestiona el estado de una aplicación Vue?
3. ¿Qué es Pinia?
4. ¿Qué factores influyen en el rendimiento de Vue.js?
5. ¿Cuáles son sus ventajas para desarrollar aplicaciones SPA?
6. ¿Qué resultados presenta el artículo al compararlo con React y Angular?

### GRUPO 5: ANGULAR – FUNDAMENTOS Y ARQUITECTURA

**Tema:** Arquitectura estructurada y desarrollo de aplicaciones web empresariales.

**Artículo científico de referencia:**

Bielak, K., Borek, B., & Plechawska-Wójcik, M. (2022). *Web application performance analysis using Angular, React and Vue.js frameworks.*

Revista: Journal of Computer Sciences Institute, 23.

DOI: https://doi.org/10.35784/jcsi.2827

**Aspectos que deberá investigar:**

1. ¿Qué es Angular y cuál es su propósito?
2. ¿Qué relación existe entre Angular y TypeScript?
3. ¿Cómo se estructura una aplicación Angular?
4. ¿Qué son los componentes, servicios e inyección de dependencias?
5. ¿Qué es el Data Binding?
6. ¿Qué ventajas ofrece Angular para proyectos empresariales?

### GRUPO 6: ANGULAR – RENDIMIENTO Y GESTIÓN DE DATOS

**Tema:** Gestión de datos, detección de cambios y rendimiento de aplicaciones Angular.

**Artículo científico de referencia:**

Bielak, K., Borek, B., & Plechawska-Wójcik, M. (2022). *Web application performance analysis using Angular, React and Vue.js frameworks.*

Revista: Journal of Computer Sciences Institute, 23.

DOI: https://doi.org/10.35784/jcsi.2827

**Aspectos que deberá investigar:**

1. ¿Cómo gestiona Angular los datos y eventos?
2. ¿Qué es RxJS y para qué se utiliza?
3. ¿Qué mecanismos utiliza Angular para detectar cambios?
4. ¿Cómo se organiza el flujo de datos?
5. ¿Qué factores influyen en el rendimiento de Angular?
6. ¿Qué resultados presenta el artículo respecto a React y Vue.js?

**Nota académica:** Los grupos que comparten un artículo deberán analizar diferentes secciones y enfoques de la investigación. Cada grupo complementará su estudio con al menos una fuente académica adicional. Se deberá verificar la indexación de las publicaciones en la base de datos correspondiente y para el año de publicación.

## 7. ESTRUCTURA DE LA EXPOSICIÓN

Cada grupo deberá preparar una presentación de aproximadamente 8 a 10 diapositivas.

| Diapositiva | Contenido |
|---|---|
| 1 | Portada: tema, integrantes y curso. |
| 2 | Presentación de la tecnología Frontend. |
| 3 | Características y arquitectura principal. |
| 4 | Componentes y funcionamiento. |
| 5 | Análisis del artículo científico. |
| 6 | Metodología y resultados de la investigación. |
| 7 | Ventajas, limitaciones y aplicaciones. |
| 8 | Ejemplo de aplicación en Ingeniería Web. |
| 9 | Análisis crítico y comparación con otras tecnologías. |
| 10 | Conclusiones y referencias bibliográficas. |

**Recomendación:** La exposición no debe limitarse a copiar información del artículo. Los estudiantes deberán interpretar los resultados, explicar los conceptos con sus propias palabras y relacionar la investigación con situaciones reales del desarrollo web.

## 8. PREGUNTAS ORIENTADORAS PARA EL ANÁLISIS

Cada grupo deberá responder las siguientes preguntas:

1. ¿Qué necesidad del desarrollo de aplicaciones web busca resolver esta tecnología?
2. ¿Qué características técnicas la diferencian de las otras tecnologías?
3. ¿Qué ventajas y desventajas presenta?
4. ¿Qué evidencias científicas presenta el artículo para respaldar sus resultados?
5. ¿Qué tipo de proyecto web recomendarían desarrollar con esta tecnología?
6. ¿Consideran que esta tecnología es adecuada para proyectos de gran escala? ¿Por qué?

### Pregunta integradora para toda la clase

**Si tuvieran que desarrollar un sistema web empresarial, ¿elegirían React, Vue.js o Angular?**

Sustenten su respuesta considerando:

- Rendimiento.
- Escalabilidad.
- Arquitectura.
- Facilidad de mantenimiento.
- Curva de aprendizaje.

## 9. ACTIVIDAD DE RETROALIMENTACIÓN ENTRE GRUPOS

Después de cada exposición, los estudiantes participarán mediante preguntas y comentarios técnicos.

Se proponen las siguientes actividades:

- Un equipo formula una pregunta al grupo expositor.
- Los estudiantes identifican una ventaja y una limitación de la tecnología presentada.
- El equipo expositor responde utilizando los argumentos del artículo científico.
- El docente complementa las respuestas y establece relaciones con las otras tecnologías.

## 13. RESULTADO ESPERADO

Al terminar las dos horas de trabajo, se espera que los estudiantes hayan comprendido las características fundamentales de React, Vue.js y Angular, conozcan sus diferencias arquitectónicas y puedan argumentar qué tecnología sería más apropiada para distintos escenarios de desarrollo de aplicaciones web.

La finalidad no es solamente conocer tres tecnologías, sino desarrollar competencias de investigación, lectura científica, análisis crítico y comunicación técnica.
